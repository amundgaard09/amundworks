# ICARUS - NATURAL LANGUAGE ENGINEERING ASSISTANT PLATFORM

## What is ICARUS?

ICARUS is a platform inspired by JARVIS from Iron Man. It is a natural language engineering assistant that understands natural language and can see. Icarus also includes a Durendal-internal API to enable Icarus to use various Durendal services, such as the DuraPy library, the Parabellum Server platform, the Vanguard Database, and other internal services, as well as an external API to enable Icarus to use external services.

## What can ICARUS do?

Icarus talks, listens, and responds to natural language queries. It can also see and respond to visual inputs via OpenCV, such as hand gestures and facial recognition.
